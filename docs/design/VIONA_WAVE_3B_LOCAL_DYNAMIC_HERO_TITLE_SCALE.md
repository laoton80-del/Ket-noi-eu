# VIONA WAVE 3B — Local Dynamic Hero Title Scale

**Pack:** `VIONA.WAVE_3B.LOCAL_DYNAMIC_HERO_TITLE_SCALE.1`

## Intent

Light +8% title scale for Local (Travel received ~+13% in `TRAVEL_DYNAMIC_HERO_TITLE_SCALE_FINAL.1`). Local already had strong composition; this keeps both hubs in the same premium family without oversizing Local.

## Typography delta

| Token | Before | After | Δ |
|-------|--------|-------|---|
| `headline` | 26 / 32 | 28 / 35 | +7.7% / +9.4% |
| `headlineNarrow` | 22 / 28 | 24 / 30 | +9.1% / +7.1% |
| `subtitle` line-height | 21 | 22 | +1px |
| `subtitle` opacity | 0.90 | 0.94 | +4pt |
| Title shadow | none | radius 5, α0.68 | subtle depth |

Hero height, image, CTA row, trust strip unchanged.
