# VIONA WAVE 3B — Travel + Local Dynamic Hero Typography Premium Scale 2

**Pack:** `VIONA.WAVE_3B.TRAVEL_LOCAL_DYNAMIC_HERO_TYPOGRAPHY_PREMIUM_SCALE.2`

## Summary

Premium spacious hero typography with ratio-based line-heights and explicit vertical rhythm (kicker→title 18px, title→subtitle 22px, subtitle→meta/CTA 26px on desktop).
