## 0. PURPOSE

This protocol exists to keep VIONA coherent while it grows from reconstruction into a global production system.

It prevents five classes of drift:

1. **Product drift** — VIONA being reduced to a booking app, AI demo, travel app, wallet, merchant dashboard, social feed, or visual prototype.
2. **Truth drift** — UI, mocks, generated images, tests, or plans being presented as production capability.
3. **Authority drift** — AI/agents acting beyond explicit permission.
4. **Economic drift** — uncontrolled AI/provider costs creating structural losses.
5. **Engineering drift** — parallel agents, hidden mutations, unbounded retries, or stale evidence changing the system without governed review.

The governing principle is:

> **Useful intelligence + real execution + human control + production truth + sustainable economics + safety.**

# 12. ZERO-LOSS ECONOMIC LAW

VIONA must never structurally subsidize unlimited variable-cost behavior.

For every costly action, one of the following must exist:

- subscription allowance;
- paid credit;
- pass-through provider charge;
- transaction margin/fee;
- bounded promotional subsidy;
- explicit internal budget.

A useful operating inequality is:

> `EXPECTED_VIONA_REVENUE > AI_COST + PROVIDER_COST + PAYMENT_COST + EXPECTED_SUPPORT_AND_FAILURE_COST + RISK_RESERVE`

Unknown or unbounded cost must not be executed blindly.

If cost is unknown/unbounded:

- block;
- pre-quote;
- request user confirmation for a bounded amount;
- require credits/payment;
- downgrade to deterministic/manual assistance;
- use a lower-cost model;
- use cached/static/local logic.

## 12.1 Cost Governor

Prefer layered controls:

1. deterministic/local logic first;
2. model routing by quality/cost;
3. entitlement budget;
4. per-action ceiling;
5. account/month loss ceiling;
6. provider-specific limits;
7. bounded retry;
8. abuse/rate protection.

Free must provide real utility, not an empty demo.

Do not use dark patterns or intentionally cripple safety/privacy/core usefulness to force payment.
