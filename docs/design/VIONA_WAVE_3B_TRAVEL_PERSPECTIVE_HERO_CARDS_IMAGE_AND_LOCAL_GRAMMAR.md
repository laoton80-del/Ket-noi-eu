# VIONA Wave 3B — Travel Perspective Hero Cards (Image + Local Grammar)

**Wave ID:** `VIONA.WAVE_3B.TRAVEL_PERSPECTIVE_HERO_CARDS_IMAGE_AND_LOCAL_GRAMMAR.1`

## Goal

Align “Góc nhìn du lịch” with Local/Home premium card grammar while keeping Travel midnight/cyan/journey identity.

## Changes

### Card grammar (Local/Home parity)
- `TravelIconCapsule` + status pill + selected checkmark (top row)
- Full-bleed hero cover + left text scrim + bottom gradient veil
- Flagship title/subtitle typography with semantic glow
- Badge kicker preserved below capsule row
- CTA “Chọn góc nhìn này” preserved

### Metrics
- Desktop ≥1024: 148px height, 12px gap (Local-like rhythm)
- Tablet 520–1023: 136px, 2-col wrap
- Mobile <520: 128px stack

### Assets
Dedicated perspective PNGs in `assets/viona/travel/` (see mapping below).

### Section rhythm
- Kicker aligned with flagship row typography
- Section opacity 0.96 (was 0.88)
- Compact secondary-zone spacing — not heavier than opening stack
